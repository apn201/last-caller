# Design: ANSI art pass (S1b)

## Approach

All art is generated by Python scripts so it can be tweaked and rebuilt.
Screens are composed from three layers: a cell canvas (characters), a pixel
layer (square pixels, half a row high, turned into `▀ ▄ █`), and shade
characters for gradients.

## Tools (`tools/ansi/`)

- `build.py`: `Canvas` (put, text, fill, box, gradients, stars, rivets),
  `PixelLayer` (set, rect, line, paint, flush), `shade()` (back/front colour
  and coverage to a shade character; one colour must be 0-7 because it
  becomes the background), a 5x5 title font (`title5`, three rows tall), a
  big 8x12 logo font (`logo`: face gradient, white highlight edge, blue
  extrusion), and the SGR writer (`sgr()` emits the smallest change; bold is
  cleared with a reset). Output is UTF-8, CRLF, `ESC[0m ESC[2J ESC[H` first.
  `python tools/ansi/build.py [names]` runs the scripts.
- `render.py`: parses ANSI like the browser terminal (same palette,
  80 columns, deferred wrap), draws block and box characters from geometry
  and letters from a system monospace font (preview only). `--menu` overlays
  the options and checks the option area.
- `screens/_common.py`: Earth, the ship (full and mini), ELIZA's ring, bezel
  frame, dividers, hazard stripes, status lights, grille.
- `img2ans.py` (optional) is not part of this slice.

## Menu option areas

The board clears the screen, draws the art, then writes each option at
`ESC[row;colH` (`menus.h`). The art therefore keeps those cells as blank
black cells inside a frame; `render.py --menu` checks this and a negative
test (the wrong art for a menu) confirms the check reports clashes.

## Code changes

- `sysop.h`, `cmd_sysop.h`: remove the Legend door settings (the menu line,
  the `D` command, the `SYSOP_DOORS` handler and `sysopDoors`).
- `user_editor.h`: remove the forest-fights field and renumber the fields
  that follow (Real name 8, Location 9, Gold 10).
- `stream.h`, `board.h`: `plainArt()` shows `ASCII/LOGIN/WELCOME.ASC` to a
  caller without ANSI (before this, the ASCII welcome was never shown).
- `legend.h` still names `ANSI/DOORS/TAVERN.ANS` in unreachable Legend code
  with a text fallback; the file is deleted.
