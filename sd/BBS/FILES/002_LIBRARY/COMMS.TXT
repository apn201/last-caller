HALCYON COMMUNICATIONS AND DIAGNOSTICS MANUAL
Rev. 3, 28 Oct 1998. For crew use. Filed by ELIZA.
===============================================================================

1. THE BOARD

   The bulletin board runs on the ship's 486, behind the navigation seat. It
   shares the ship's modem with the packet gateway. One caller may use each
   node. The ground reaches it through the account MCC.

   Limits. A message line holds 254 characters. Do not hold a key down in the
   editor: a run of 20 zeros, which the line tool fills in, overruns the line
   buffer and the board restarts. Nothing is lost but the post.

2. THE DIAGNOSTICS DOOR

   Doors, then Diagnostics. The mission computer answers a system query by its
   code. Type the code. Spaces and dashes do not matter. QUIT leaves.

   She answers what is asked. Please ask exactly.

   A code that opens another host is entered the same way. See section 6.

3. QUERY CODES

   1xx  POWER AND ATTITUDE
        100  Power bus, source and solar array
        101  Attitude and rate

   2xx  CREW AND CABIN
        200  Crew count, aboard at launch and aboard now
        201  Cabin atmosphere

   3xx  COMMUNICATIONS
        300  Downlink and uplink, and the last acknowledgement
        301  Telephone line, modem and node

   4xx  PAYLOAD
        400  Payload module, power and cooling

   5xx  MISSION CLOCK
        500  Mission day

   6xx to 9xx are reserved for Mission Operations. They are not printed here.
   Code lists for Mission Operations are issued on request, in writing.

4. IF THE BOARD DOES NOT ANSWER

   Wait one minute. If the board still does not answer, the ship may be in
   shadow. Try again when the sun is up.

5. NOTES

   The ground reaches the ship through the relay once an hour. A message is
   forwarded at the top of the hour. A message sent at one minute past waits
   fifty-nine.

   There is no code for the weather. Please ask the Commander.

6. MISSION OPERATIONS (NOT FOR CREW USE)

   Authorisation codes issued by the Office of the Founder are entered as
   queries, in the same way as the codes above. A code opens the host it names.

   Outbound queues on the payload host are held until released. Syntax:

        release QUEUE DESTINATION

   A queue is named in its header. The destination is the link it is
   addressed to. A held queue is released when its hold condition is cleared.
