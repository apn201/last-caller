## 2. Trouble log

- M: Login screen. It says "you have no account" and sends me to a service label. I tried my own handle and "NEW", which both failed. Only the label (ADMIN/ADMIN) works. After that, the SHIP> prompt, SOURCE RTG, "press K, no ENTER", then CREW, then the sign-up questions. It worked because every step told me the next one. A real customer would hesitate at "Unknown caller".
- L: Login screen text is a puzzle, not a sign-up prompt. Fine for a game, but it does not say that typing is needed rather than a key.
- L: After sign-up an ELIZA conversation with numbered choices appeared before the menu. "Press a number, no ENTER" was clear.
- L: Bulletin pager: Q goes back to the bulletin list, a second Q to the main menu. Consistent with "back one level".
- M: Bulletin list says "Bulletin #, then ENTER (Q goes back at once)". Mixing "ENTER needed" and "no ENTER" on the same screen made me check each prompt. The prompts did say which, so no failure.
- L: Pressing Q at the main menu after ELIZA's panel redrew the menu and an ELIZA panel popped up over it. I pressed a key to dismiss it. The menu then showed again, which is fine, but it was an extra step.
- L: Main menu changed between visits. "[R] Crew manifest" appeared later and the layout moved. Harmless, but the letters moved around.
- M: Snake door says "Moves (W A S D, Q quits)". I typed "d" with ENTER and it moved one step. I did not learn whether keys work without ENTER. Q alone quit at once. Unsure for a minute whether the game wants ENTER for each move.
- M: Task 8, node chat. The main menu has "Chat with the SysOp" (C) only. Who is online lists other nodes, but I found no way to talk to a caller. I used C instead.
- L: The message list shows only a range of messages (10 to 29), so I was unsure whether older ones existed. The prompt "ENTER = first new, P = earlier" explains it.
- L: Reply editor: "/S saves" is clear. Pressing ENTER on an empty line did not save, which is what I expected.
- L: File prompt says "[#] Open (number, ENTER)". Clear.
- Pleasure: the galley rota file. The footer on every reader ("SPACE next B back Q back X main ? keys") is always the same. X to the main menu worked everywhere I tried.
