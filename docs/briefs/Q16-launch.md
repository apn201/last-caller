1. `tools/test/e2e_telnet.py --capture DIR`: after named steps, save the

## C. Recording mode for the browser terminal

For screen capture in OBS. In `shared/web/terminal.html` (the hook
regenerates the header; never edit `src/net/web_terminal.h`):

- `?rec=1` hides the button bar and the cursor pointer, scales the 80x25
  canvas by the largest integer that fits the window (nearest-neighbour,
  `image-rendering: pixelated`), black letterbox, keyboard still works.
  `?speed=300|2400|14400|28800` presets the modem speed. `?dial=1` dials
  on load.
- No new menu option, nothing caller-visible changes without the
  parameter. Test on staging in a 1920x1080 window and on a phone.

## E. Judge savegames

Decision (Juha, 13 Nov): judges are told to start from the beginning, but
can load a saved game if short of time. Add `tools/make-savegame.py`:
given a card root, a handle, a password and a stage (`act2` or `act3`),
it creates a normal caller account whose story record holds exactly the
flags a fresh player has at the start of that act (take them from the
e2e run, not by hand). Passwords come from the command line or an
environment variable, never from a file in the repo. The accounts are
ordinary callers: no SysOp level, no read-only crew account, and
`deploy/reset.sh` must not delete them unless asked (`--keep-savegames`
default on). Document the command in `docs/DEPLOY.md` for the host. Test
on a disposable card copy on staging: log in as each, check the act gate
and that the rest of the game plays to an ending from there (extend the
e2e with an optional `--from act2|act3`).
